# Onshape Lid Feature

A custom Onshape FeatureScript for generating a printable enclosure lid from a selected planar top rim.

The goal is intentionally narrow: **select the top rim of an existing enclosure, click one feature, and get the repetitive lid geometry automatically**.

This project started from a real manually modeled enclosure/lid and is being developed incrementally around practical 3D-printing workflows rather than as a general-purpose enclosure generator.

## Current status

**Working prototype — V0.4**

The feature currently:

- creates a **separate solid lid part**
- follows the enclosure's existing outer perimeter
- creates a solid locating plug from the actual inner opening
- applies configurable fit clearance
- adds four quarter-circle corner bosses to the enclosure
- generates matching screw geometry
- supports M2, M2.5, M3, and M4 screw presets
- cuts lid clearance holes
- cuts 90° countersinks
- cuts blind pilot holes into the enclosure bosses
- leaves the result as ordinary Onshape solid geometry that can be filleted, drilled, modified, etc. downstream
- does all of this without generating a pile of permanent sketches

The current version has been tested on a simple rectangular enclosure. Validation against more complicated real-world enclosure geometry is the next milestone.

## Why this exists

Modeling a basic enclosure is easy.

Modeling the lid is repetitive:

1. trace/project the enclosure perimeter
2. create the lid plate
3. create locating geometry
4. create corner bosses
5. place four screw locations
6. cut pilot holes
7. cut lid clearance holes
8. create countersinks
9. keep all of it aligned when dimensions change

This FeatureScript packages that repeated work into one feature.

The design principle is:

> The enclosure geometry is authoritative. The feature should derive the lid from the enclosure instead of asking the user to re-enter dimensions that already exist in the model.

## Installation

### 1. Create a Feature Studio

In the same Onshape document as your Part Studio:

1. Click the **+** at the bottom-left of the document.
2. Choose **Create Feature Studio**.
3. Give it a name such as `Lid`.

### 2. Copy the FeatureScript

Open [Lid.fs](./Lid.fs) and copy the complete file into the Feature Studio.

The repository currently uses:

```featurescript
FeatureScript 3070;
import(path : "onshape/std/geometry.fs", version : "3070.0");
```

If Onshape has moved to a newer FeatureScript version, use the version/import lines generated by a newly created Feature Studio and keep the rest of `Lid.fs` below them.

### 3. Commit

Click **Commit** in the Feature Studio.

### 4. Use the custom feature

Return to your Part Studio. The feature should appear in the **Custom features** dropdown in the Part Studio toolbar as:

**Lid V0.4**

Select it, then select the planar top rim face of the enclosure.

## Parameters

| Parameter | Current default | Purpose |
|---|---:|---|
| Lid thickness | 2.5 mm | Thickness of the outer lid plate |
| Fit clearance | 0.25 mm | Per-side clearance between enclosure opening and locating plug |
| Locating depth | 2 mm | Distance the solid locating plug extends into the enclosure |
| Boss diameter | 14 mm | Diameter used to generate the four quarter-circle corner bosses |
| Screw size | M3 | Selects lid clearance-hole and countersink geometry |
| Pilot diameter | 2.2 mm | Diameter of blind unthreaded pilot holes in the printed bosses |
| Pilot depth | 10 mm | Depth of the blind pilot holes |

### Screw position

Screw centers are derived automatically from boss diameter.

Current rule:

```
screw inset = boss diameter / 6
```

The inset is measured from each adjacent inside wall along the two opening-edge directions.

This was selected after testing because the earlier `D/4` rule placed the screw too close to the curved edge of the quarter-circle boss.

## Screw presets

The current hard-coded lid geometry is:

| Screw | Clearance hole | Countersink diameter | Included angle |
|---|---:|---:|---:|
| M2 | 2.4 mm | 4.0 mm | 90° |
| M2.5 | 2.9 mm | 5.0 mm | 90° |
| M3 | 3.4 mm | 6.0 mm | 90° |
| M4 | 4.5 mm | 8.0 mm | 90° |

These are practical defaults, not a substitute for checking the actual screw hardware you intend to print around.

The pilot hole is intentionally user-adjustable because thread-forming behavior depends on screw geometry, print material, printer calibration, layer orientation, and desired bite.

## What the feature modifies

The feature creates/updates two solids:

1. **Enclosure** — receives the four corner bosses and blind pilot holes.
2. **Lid** — remains a separate printable part and receives the locating plug, clearance holes, and countersinks.

The finished Part Studio should still contain **two parts**, not a collection of helper solids.

Temporary construction bodies are consumed/deleted inside the FeatureScript.

## Current geometry assumptions

V0.4 is intentionally narrow and conservative.

It currently expects:

- one selected **planar top rim face**
- a solid enclosure body
- an outer rim loop and one inner opening loop
- an ordinary four-corner opening
- exactly four inner corner vertices
- two opening edges meeting at each corner
- a normal enclosure whose deepest extent along the rim normal corresponds to the enclosure floor

The corner-boss implementation is currently aimed at ordinary rectangular/90° enclosure openings.

If the opening has rounded corners, extra vertices, multiple openings, unusual topology, or nonstandard floor geometry, the current boss logic may reject it or produce unintended geometry.

That is deliberate: the project prefers a useful error over silently generating bad geometry.

## Known limitations / not implemented yet

- rounded or multi-segment inside corners
- optional lid overhang/flange
- lead-in chamfer on the locating plug
- custom screw-size table
- alternate fastener styles such as heat-set inserts
- optional disabling of bosses/fasteners
- multiple enclosure openings
- generalized boss placement for arbitrary corner geometry
- validation against the original more-complex enclosure that motivated the project

## Design notes

The feature deliberately avoids recreating the enclosure from width/length/corner-radius parameters.

Instead it works from existing B-rep topology:

1. select the top rim face
2. collect its boundary edges
3. split the boundary into connected loops
4. treat the longest loop as the enclosure outer perimeter
5. use the remaining loop as the opening
6. fill/extrude the outer loop to create the lid plate
7. fill/extrude the inner loop to create the locating plug
8. offset the locating plug side faces inward for fit clearance
9. generate corner bosses by intersecting cylinders with the opening volume
10. cut lid and boss screw geometry with temporary solid cutters

This keeps the feature compact and avoids leaving dozens of sketches/features behind.

For more implementation detail, see [DEVELOPMENT.md](./DEVELOPMENT.md).

## Normal downstream modeling still works

The generated lid is ordinary Onshape solid geometry.

You can add normal Part Studio features after it, such as:

- fillets
- chamfers
- holes
- text/embossing
- vents
- cutouts
- mounting features

As with any parametric CAD model, a downstream feature can lose references if upstream topology changes dramatically, but ordinary dimension edits should regenerate normally.

## Development philosophy

This feature is intentionally **not** a giant enclosure generator.

The working rule is:

- start narrow
- make one operation reliable
- test it
- preserve working code
- add the next capability incrementally
- do not add parameters unless testing proves they are useful
