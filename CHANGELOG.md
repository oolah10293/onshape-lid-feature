# Changelog

## V0.4
- Added screw-size selector for M2, M2.5, M3, and M4.
- Added lid clearance holes.
- Added 90° countersinks.
- Added blind pilot holes in enclosure bosses.
- Added user parameters for pilot diameter and pilot depth.
- Added validation for countersink depth, pilot depth, and pilot diameter.
- Adjusted screw location rule from D/4 to **D/6** after visual testing showed D/4 placed the screw too close to the curved boss edge.

## V0.3
- Added four quarter-circle corner bosses to the enclosure.
- Added configurable boss diameter.
- Bosses extend from the enclosure floor to the underside of the locating plug.
- Kept the lid as a separate solid part.

## V0.2
- Added solid locating plug.
- Added configurable fit clearance.
- Added configurable locating depth.
- Preserved two-part result: enclosure + lid.

## V0.1
- Initial working feature.
- Select planar top rim face.
- Derive the outer enclosure perimeter.
- Create a separate solid lid plate with configurable thickness.
